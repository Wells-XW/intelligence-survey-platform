# Intelligence Survey Platform（智能学术调查平台）

## 项目概述

基于 ChatGPT Deep Research 产出的一份竞品与需求调研报告（`deep-research-report.md`），开发一个面向学术研究的智能在线调查平台。平台将集成 AI 驱动的问卷设计、研究设计辅助、测量工具库、样本管理、数据质控、分析可视化、伦理合规提示、知识库检索等功能模块。

## 项目类型

- **分类**: 科研项目（产品开发实施）
- **与博士论文关系**: 独立项目，不纳入论文正文
- **产出目标**: 可运行的 MVP 产品

## 核心差异化

1. **学术规范性内置** — 而非事后补救。问卷设计阶段即嵌入 AAPOR 等学术标准、信效度检验、伦理合规提示。
2. **AI 驱动全流程** — 从研究设计→问卷生成→数据分析→报告撰写，每个环节有 AI 助手。
3. **风险自动检测** — 测量偏差、样本偏倚、伦理问题、统计误用等实时提示。
4. **中文优先 + 国际兼容** — 深度支持中国学术生态（PIPL 合规、CNKI 集成），同时兼容 GDPR 等国际标准。

## 竞品格局

| 竞品 | 优势 | 致命短板 |
|------|------|---------|
| Qualtrics | 功能最全，学术界渗透率高 | 成本极高（$420/月起），学习曲线陡 |
| SurveyMonkey | 易用，模板丰富 | 缺少学术专用模块 |
| LimeSurvey | 开源免费，数据可控 | 界面陈旧，AI 能力薄弱 |
| 问卷星 | 国内市场主导，功能全面 | 缺少学术研究引导和 AI 能力 |
| Prolific | 学术受试者招募质量高 | 仅做招募，无问卷设计功能 |

**市场空白**: 尚无一款同时满足"AI 智能 + 学术规范 + 中文生态 + 可负担价格"的调查平台。

## 技术栈建议

- **前端**: React + TypeScript (Web) / Flutter (Mobile)
- **后端**: Python FastAPI (问卷逻辑 + 数据分析) + Node.js Express (API Gateway)
- **AI 服务**: LLM API（问卷生成、风险检测、摘要）+ 本地模型（文本分类、异常检测）
- **知识库**: QMD（已有）+ 文献检索 API（CNKI, PubMed, Semantic Scholar）
- **数据存储**: PostgreSQL（结构化）+ Elasticsearch（日志/搜索）+ MinIO（文件）
- **部署**: Docker + Kubernetes（多租户隔离）
- **安全**: AES-256 加密 + GDPR/PIPL 合规 + 审计日志

## 路线图（0–18 个月）

### Phase 1: 基础建设（0–6 个月）
- 市场/学术需求深入调研
- 技术架构设计与技术选型
- 核心模块 MVP：问卷设计器 + 基础分析
- 数据安全与权限机制

### Phase 2: AI 集成（6–12 个月）
- AI 问卷生成
- 知识库检索集成
- 数据质量控制模块
- 伦理提示引擎
- 内部测试

### Phase 3: 完善与发布（12–18 个月）
- 分析可视化工具
- API/导出功能完善
- Beta 测试与用户反馈
- 学术合作试点

## 商业模式

- **学术用户**: 基础功能免费/低价（学生半价，教师七折）
- **企业用户**: 分档订阅（基础版 ¥数千/年，高级版 ¥数万/年）
- **按项目付费**: 单次调查按响应量计费
- **增值服务**: 样本配额、定制分析、专属面板
