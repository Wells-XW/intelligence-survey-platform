# MVP 内部测试计划

## 测试目标

验证 Intelligence Survey Platform Phase 1 + Phase 2 的 11 项模块在学术研究场景下的功能完整性、可用性和稳定性。

## 测试范围

```
Phase 1: 基础建设 ✅
├── 问卷 CRUD + SurveyJS Creator 编辑器
├── 用户认证 JWT + RBAC 权限
├── 审计日志 + PIPL 隐私
└── 数据采集 + Analytics 引擎 + ECharts 可视化

Phase 2: AI 集成 ✅
├── AI 问卷生成引擎（DeepSeek-R1 + SQP 评估）
├── 知识库与文献检索（PubMed/Semantic Scholar/CNKI）
├── 数据质量控制增强（缺失模式/不一致/注意力/响应时间）
├── 伦理合规与风险提示引擎（PIPL/GDPR/偏差/敏感信息）
└── 13 个学术量表预置 + 6 个方法学指南
```

## 测试阶段

### α 测试（内部，Week 1）

| # | 测试场景 | 步骤 | 预期结果 |
|---|---------|------|---------|
| 1 | 注册+登录流程 | 注册新用户 → 登录 → Token 刷新 | JWT access+refresh 正常，15min 过期刷新 |
| 2 | 创建问卷 | 新建 → 添加 10 题 → 拖拽排序 → 保存 | SurveyJS Creator 正常工作，JSONB 存储正确 |
| 3 | AI 生成问卷 | 输入研究主题 → SSE 流式生成 → 保存 | 生成 15-25 题，含知情同意段落，SQP 评分 >0.6 |
| 4 | 量表导入 | 浏览量表库 → 导入 RSES → 插入问卷 | 10 题添加到问卷，reverse_scored 标注正确 |
| 5 | 文献检索 | 搜索 "social media mental health" → 保存 3 篇 | PubMed + Semantic Scholar 返回结果，去重正常 |
| 6 | 发布+填答 | 发布问卷 → 匿名填答 10 份 → 含 PIPL 知情同意 | 填答正常，IP 匿名化，PIPL 标记正确 |
| 7 | 数据分析 | 查看描述统计/Cronbach's α/交叉表/质量指标 | 图表渲染正常，α 计算正确 |
| 8 | 数据质量 | 缺填/不一致/注意力检测/响应时间分布 | 6 卡指标完整展示 |
| 9 | 伦理合规扫描 | 运行全量表扫描 → 查看 PIPL/GDPR/偏差结果 | 风险雷达图显示，建议列表完整 |
| 10 | 权限控制 | Viewer 试图删除问卷 → Owner 切换权限 | 403 拒绝正确，权限变更生效 |

## Bug 分类

| 级别 | 定义 | 示例 |
|------|------|------|
| P0-Critical | 阻塞功能，数据丢失 | 保存失败，Token 不刷新导致无限 401 |
| P1-High | 核心功能缺陷 | AI 生成 JSON 解析失败，Cronbach's α 计算错误 |
| P2-Medium | 次要功能问题 | 搜索无结果时无提示，图表标签截断 |
| P3-Low | UI 瑕疵 | 按钮对齐，移动端响应式，颜色偏差 |

## 测试环境

- **前端**: Vite dev server (localhost:5173)
- **后端**: Uvicorn (localhost:8000)
- **数据库**: PostgreSQL 16 Docker
- **AI**: DeepSeek API (deepseek-chat)
- **文献检索**: PubMed E-utilities + Semantic Scholar API
