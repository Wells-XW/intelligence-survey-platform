## 技术选型关键决策
- **API Gateway**: Express → **Fastify** (2026年行业共识，5x更快)
- **对象存储**: MinIO → **Garage** (MinIO 社区版移除管理控制台，Garage Apache 2.0 更安全)
- **UI 库**: 选定 **shadcn/ui** (学术中性风格 + 完全可控)
- **状态管理**: **Zustand** (客户端) + **TanStack Query** (服务端)
- **问卷编辑器**: **SurveyJS 社区版** (MVP快速验证) → dnd-kit 自研 (差异化)
- **LLM 策略**: **DeepSeek-R1 中文主力** (成本仅为 GPT-4o 5%，中文质量更高) + Claude Opus 4 英文 + GPT-4.5 mini 批量
- **部署**: **Docker Compose 单机** (MVP) → Kubernetes (规模化)
- **PWA**: Workbox + IndexedDB/Dexie.js 离线问卷填写
