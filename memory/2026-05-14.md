## 技术选型关键决策
- **API Gateway**: Express → **Fastify** (2026年行业共识，5x更快)
- **对象存储**: MinIO → **Garage** (MinIO 社区版移除管理控制台，Garage Apache 2.0 更安全)
- **UI 库**: 选定 **shadcn/ui** (学术中性风格 + 完全可控)
- **状态管理**: **Zustand** (客户端) + **TanStack Query** (服务端)
- **问卷编辑器**: **SurveyJS 社区版** (MVP快速验证) → dnd-kit 自研 (差异化)
- **LLM 策略**: **DeepSeek-R1 中文主力** (成本仅为 GPT-4o 5%，中文质量更高) + Claude Opus 4 英文 + GPT-4.5 mini 批量
- **部署**: **Docker Compose 单机** (MVP) → Kubernetes (规模化)
- **PWA**: Workbox + IndexedDB/Dexie.js 离线问卷填写

## 安全架构关键决策
- **JWT 双令牌**: access (15min, 短期风险控制) + refresh (7d, 一次性轮转防重放)
- **RBAC 粒度**: Survey 级别 (owner>editor>viewer)，通过 SurveyPermission JOIN 实现
- **多租户隔离**: 不使用简单 owner_id 过滤器，而是 JOIN SurveyPermission 表（为未来问卷共享预留）
- **速率限制**: 内存实现 60 req/min（MVP 阶段不引入 Redis 依赖）
- **审计日志**: 追加模型 BigInteger PK，记录 action/resource/IP/user_agent
- **PIPL**: 注册时自动创建隐私政策同意记录，SurveyResponse Schema 含合规说明
- **bcrypt 版本**: 锁定 4.0.x（passlib 1.7.4 不兼容 bcrypt 5.x）
- **Python 3.9**: `from __future__ import annotations` 实现现代类型提示
