### 核心功能
1. **分半信度**: Spearman-Brown 校正 + 奇偶/前后两法
2. **题总相关**: corrected r + alpha-if-deleted + 质量标注
3. **KMO/Bartlett**: numpy 矩阵运算 + scipy chi2 检验
4. **构念分析**: 多构念 α + 分半 + 构念间相关矩阵
5. **APA 报告**: 5 节结构化报告自动生成
6. **常模对标**: 查询 KnowledgeScale 表，按差值排名

### 技术亮点
- 所有数学运算纯 Python (numpy/scipy)，无 AI 依赖
- Spearman-Brown 用 formula `2r/(1+r)` 实现
- KMO 用反影像相关矩阵 (AIC) 计算
- scipy 不可用时自动回退到 Wilson-Hilferty 近似
